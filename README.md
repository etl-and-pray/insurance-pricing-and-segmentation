# Insurance Analytics Portfolio: End-to-End Pricing & Customer Segmentation Case

Комплексный сквозной проект по анализу данных страховой компании. Кейс охватывает весь цикл аналитической работы: от неконтролируемого машинного обучения (кластеризации) и проверки продуктовых гипотез (A/B-тестирования) до презентации результатов топ-менеджменту по принципу пирамиды Минто.

---

## Описание проекта

В проекте исследуются данные по полисам страхования выезжающих за рубеж (ВЗР). Главная бизнес-цель — оптимизировать ценообразование полисов с помощью кластеризации клиентской базы, проверить эффективность нового подхода через A/B-тестирование и защитить инициативу перед руководством.

Проект состоит из трех взаимосвязанных этапов:
1. **Сегментация клиентов (Кластеризация):** Анализ базы данных полисов и клиентов, обработка смешанных признаков, применение алгоритмов K-Means, иерархической кластеризации и K-Prototypes для выявления ключевых групп клиентов и их влияния на убыточность.
2. **A/B-тестирование ценообразования:** Оценка эффективности нового подхода к формированию стоимости полиса (на базе кластерных групп) по сравнению с традиционной оценкой рисков. Анализ метрик (цена, конверсия в оформления, убыточность) с помощью t-тестов.
3. **Бизнес-отчетность и сторителлинг:** Подготовка лаконичного аналитического отчета и презентации для менеджмента с обоснованием бизнес-эффекта и рекомендациями по внедрению в продакшен.

---

## Стек и инструменты
* **Python**, Pandas, NumPy, Scikit-learn, K-Modes
* **Статистический анализ:** t-test, проверка гипотез, продуктовые метрики
* **Машинное обучение (Unsupervised):** K-Means, Hierarchical Clustering, K-Prototypes
* **Инструменты презентации:** Jupyter Notebook, PDF-отчеты (принцип пирамиды Минто)

## Структура репозитория
* `notebooks/`
